## 여러 게임에서 확인된 취향

새 게임을 만들 때도 먼저 확인할 것들이다.

- **그림**: 굵고 또렷한 간단한 2D 도트(「뭉툭 도트」). 자동 명암으로 뭉개진 그림은 싫어한다.
- **진행 방식**: 새 그림은 게임에 넣기 전에 시안부터 보여 주고 고르게 한다.
- **땅과 자연**: 산, 땅의 격자무늬, 외곽의 이상하게 생긴 나무처럼 부자연스러운 풍경은 자연스럽게 고쳐 달라고 했다.
- **글꼴**: 세 게임(상단 키우기 · 밀리언 라이프 · 게이트 브레이크) 모두 갈무리(Galmuri) 도트 글꼴을 쓴다.
